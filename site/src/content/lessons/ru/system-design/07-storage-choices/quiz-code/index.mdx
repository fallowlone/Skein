## Сниппет 1 — схема

```sql
CREATE TABLE attachments (
  id          uuid PRIMARY KEY,
  owner_id    uuid NOT NULL,
  filename    text NOT NULL,
  content     bytea NOT NULL,   -- сырые байты файла, до 25 МБ
  created_at  timestamptz NOT NULL DEFAULT now()
);
```

## Сниппет 3 — путь записи

```js
async function publishPost(post) {
  await db.insert("posts", post);          // источник истины
  await search.index("posts", post);       // сделать ищущимся
  return post;                              // нет общей транзакции
}
```

## Сниппет 4 — endpoint загрузки

```js
// обработчик загрузки на stateless-уровне приложения
app.post("/upload", async (req, res) => {
  const buf = await readEntireBody(req);     // буферизует весь файл в памяти приложения
  await objectStore.put(key(req), buf);      // приложение проксирует каждый байт в S3
  res.json({ ok: true });
});
```

<KeyTakeaway>Решения хранения читаемы в схеме и коде: байты — в объектном хранилище (не BYTEA), LIKE с ведущим wildcard нужен инвертированный индекс, двум записям без общей транзакции — outbox или CDC, крупным загрузкам — presigned.</KeyTakeaway>

<Recap lang="ru">
Каждое решение хранения в этом разделе читаемо прямо со схемы и кода. **Колонка BYTEA/BLOB под крупные файлы** — анти-паттерн блоба-в-БД — убери её, храни байты в объектном хранилище под ключом, держи только маленькие метаданные. **LIKE с ведущим wildcard** не может использовать B-tree и полностью сканирует таблицу; починка — **инвертированный индекс** (поисковый движок или Postgres `tsvector`/GIN). **Две записи в две системы без общей транзакции** тихо расходятся при любом падении или провале — выведи второе хранилище из коммита БД через **транзакционный outbox** или **CDC**, никогда best-effort. А **обработчик загрузки, что буферизует или проксирует байты**, OOM-ит и насыщает уровень приложения — убери приложение с пути байтов **presigned-ссылкой**, чтобы клиент грузил прямо в хранилище. Senior-привычка — найти, где байты и гарантии реально живут, и выбрать изменение, что уважает свойства хранилища, а не заклеивает цену.
</Recap>
