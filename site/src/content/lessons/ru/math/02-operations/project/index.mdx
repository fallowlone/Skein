<Recap lang="ru">
Это и есть цикл за каждой настоящей арифметической задачей: прочитай вопрос, реши, какое из четырёх действий на него отвечает, выполни его вручную по одному разряду — с переносом и займом там, где разряд переполняется или не хватает, — а затем докажи ответ обратным действием. Сделав это один раз на целом плане вечеринки, ты превращаешь четыре отдельных урока в один связный навык: ты больше не спрашиваешь «как складывать», ты спрашиваешь «какое действие нужно этому вопросу» и можешь проверить себя каждый раз.
</Recap>
