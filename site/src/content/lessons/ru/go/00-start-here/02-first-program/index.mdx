## Двенадцать строк, которые что-то делают

Создай файл `hello.go` и набери ровно это:

Запусти через `go run hello.go`. Увидишь `hi`. Этот вывод — весь цикл обратной связи Go-разработки: правишь, запускаешь, читаешь. Всё в юнитах 01–04 — удлиненная версия этих тридцати секунд.

## Сломай специально

Теперь удали одну закрывающую кавычку, чтобы строка читалась `fmt.Println("hi)`, и запусти снова. Ты не получишь `hi` и не получишь тишину — получишь ошибку с именем файла, номером строки и недостающей кавычкой, и не выполнится ничего. Так компилятор отрабатывает своё: в Go сломанный код никогда не работает наполовину. Читай ошибку сверху вниз — сначала файл, потом строка, потом чего хотело, — потому что этот порядок чтения трек будет переиспользовать в каждом юните.

Верни кавычку, запусти ещё раз, увидь `hi`. Теперь ты знаешь полный цикл: пишешь, запускаешь, читаешь вывод, — а когда код сломан, читаешь ошибку компилятора, которая тоже вывод, и обычно более полезный.

<Inset kind="why" lang="ru">
Зачем Go требует объявлять <code>package main</code> ради программы в пять строк? Потому что то же правило без изменений масштабируется на пять тысяч файлов: тулчейн всегда знает, что исполняемо, а что библиотека, по одному слову. Церемония, которая никогда не растёт, — не бюрократия; именно поэтому Go-репозиторий любого размера навигируем с первого дня.
</Inset>

<KeyTakeaway>Выполнение стартует с <code>func main</code> в пакете <code>main</code> и больше нигде. <code>go run</code> компилирует весь файл прежде, чем выполнить хоть что-то, поэтому ошибка значит: не выполнилось ничего, — читай как файл, строка, жалоба, чини, повторяй.</KeyTakeaway>

<Recap lang="ru">
Go-программа — это файл в пакете <code>main</code> с <code>func main</code>, где стартует выполнение. Разрабатываешь циклом пиши, <code>go run</code>, читай, — а когда код сломан, читаешь ошибку компилятора с файлом и строкой, потому что ничего не запускается, пока всё не скомпилировалось. Дальше: единственная привычка Go, удивляющая каждого новичка, — ошибки как обычные значения, проверяемые двухстрочным <code>if</code>, который ты напишешь тысячу раз.
</Recap>
