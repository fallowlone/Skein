<Recap lang="ru">
Сквозная линия юнита — одна дисциплина: greedy всегда выполняется и всегда что-то возвращает, поэтому единственный важный вопрос — доказуемо ли его локальный выбор глобален. Exchange argument (или stays-ahead) — то, чем вы доказываете безопасность; отсутствующий swap — как у монет {1,3,4} для 6 — сам по себе доказательство провала, а запасной вариант — DP. Для interval-задач сложное — это ключ сортировки: earliest finish для максимизации, start для merging, sweep по стартам и финишам для комнат. А для scan-greedy вроде Gas Station никогда не решайте по локальному провалу — решайте по глобальному инварианту.
</Recap>
