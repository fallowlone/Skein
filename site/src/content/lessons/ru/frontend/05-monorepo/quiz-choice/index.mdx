<Recap lang="ru">
Сквозная линия юнита — один пайплайн: граф зависимостей задаёт порядок и радиус взрыва, affected-детекция сужает каждый PR до изменённых проектов плюс их зависимых, remote cache превращает большинство из них в мгновенные попадания — и ключ кэша решает всё, где отсутствующий вход — опасный false hit, а волатильный — расточительный false miss. Ничто из этого не выживает при плохом графе, поэтому выставленные границы модулей (Nx-теги, правило enforce-module-boundaries, package exports) не дают сформироваться hub. А выбор monorepo против polyrepo — про связанность: общий код, меняющийся вместе, — в пользу monorepo; по-настоящему независимые команды — в пользу polyrepo. Теперь, когда видишь 40-минутный CI или устаревшую сборку в проде, знаешь, за какой рычаг тянуться первым.
</Recap>
