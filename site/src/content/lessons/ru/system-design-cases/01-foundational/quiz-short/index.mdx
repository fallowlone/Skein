<KeyTakeaway>Реконструируй каждый кейс по памяти — блоки KV-хранилища, путь сокращателя, frontier и дедуп краулера, лог очереди — и держишь стержень: те же ходы (партиционировать, реплицировать, дедупить) переформованные.</KeyTakeaway>

<Recap lang="ru">
Если ты смог пересобрать каждый дизайн по памяти, ты держишь стержень юнита: четыре кейса — те же ходы, переформованные. **KV-хранилище** выбирает доступность над согласованностью и складывает кольцо хеширования, кворум (`R + W > N`) и версионирование, с gossip и anti-entropy под ними. **Сокращатель URL** — задача ~100:1 на чтение, решаемая счётчиком/KGS для кодов и кешем для редиректа, с 302-против-301, меняющим аналитику на нагрузку. **Краулер** — двухступенчатый frontier (приоритет + вежливость) плюс два слоя дедупа (bloom filter для URL, хеш контента для байтов), сделанный непрерывным перекраулом по свежести и закалённый против ловушек. **Очередь сообщений** — партиционированный лог только на дозапись: партиции для параллелизма и порядка, ISR с `acks=all` для надёжности, время коммита оффсета для семантики доставки. Переносимый урок — что каждый новый запрос «спроектируй X» раскладывается на требования, оценку, выбирающую форму, несколько сложных компонентов и узкие места, что ты называешь до постройки.
</Recap>
