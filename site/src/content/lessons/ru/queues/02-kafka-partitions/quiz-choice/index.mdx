<Recap lang="ru">
Сквозная линия — один механизм в трёх ролях: hash(key) % N делает распределение, порядок по key и co-location одновременно. Из него следует всё — порядок держится только внутри partition, параллелизм consumer жёстко ограничен количеством partition, а смена N перехеширует key и ломает порядок по key, поэтому количество — это односторонняя дверь, под которую закладывают запас заранее, а не настраивают. Два продакшен-сбоя, hot-partition skew (исправляется на уровне key) и stop-the-world rebalance (укрощаются cooperative rebalancing и static membership), сводятся к одному уроку: key и количество — это и есть реальные решения дизайна, и принимаются они до того, как топик появится. Теперь, когда ты сидишь на design review по Kafka, ты узнаешь эти шесть вопросов раньше, чем их задаст кто-то другой — и сам спросишь про ключ и количество partition первым.
</Recap>
