## Сниппет 1 — запись в outbox

```sql
-- хендлер заказа, одна транзакция БД
BEGIN;
  INSERT INTO orders (id, customer_id, status, total_cents)
    VALUES ('ord_9f', 'cust_3a', 'placed', 4200);
  INSERT INTO outbox (id, aggregate_id, type, payload, created_at)
    VALUES ('evt_7c', 'ord_9f', 'order.placed', '{"order_id":"ord_9f"}', now());
COMMIT;
-- отдельно, позже, relay:
--   SELECT * FROM outbox WHERE sent = false ...
--   публикация в Kafka, затем UPDATE outbox SET sent = true
```

## Сниппет 3 — порядок коммита у консьюмера

```python
for msg in consumer:                      # at-least-once Kafka-консьюмер
    event = parse(msg.value)
    consumer.commit()                     # коммит оффсета СНАЧАЛА
    charge_payment(event.order_id,        # затем side effect
                   event.amount_cents)
```

## Сниппет 4 — обработка DLQ

```python
def handle(event):
    try:
        process(event)                       # идемпотентный side effect
    except Exception:
        send_to_dlq(event)                    # любой сбой -> DLQ
        consumer.commit()
```

<Recap lang="ru">
Каждый шов pipeline читается в коде и конфиге: outbox делает два INSERT атомарными, но publish-затем-mark у relay — at-least-once, так что консьюмеры должны делать dedup; CDC-коннектор, ключующий по aggregate_id, хранит порядок по заказу, но heartbeat.interval.ms = 0 без cap на slot — это простой из-за заполнения диска, ждущий залипания; коммит оффсета до side effect — at-most-once и тихо теряет списания, так что коммить после обработки и оставайся идемпотентным; а DLQ при первом исключении хоронит poison-сообщения под восстановимыми транзиентами, так что ретрай с бюджетом и карантин только при исчерпании. Читай границу транзакции, порядок коммита, уникальное ограничение и конфиг коннектора — именно там и живёт корректность pipeline. Теперь, когда ты проверяешь pull request, затрагивающий любое из этих четырёх мест, ты знаешь: рецензируешь не стиль — рецензируешь, будут ли списания потеряны, задвоены или молча заблокированы.
</Recap>
