<Recap lang="ru">
Если смог реконструировать каждый ответ по памяти — держишь стержень юнита: OTel — это API + SDK + Collector + OTLP; нейтральность живёт на границе приложения и размывается через вендорские SDK в коде или проприетарные процессоры Collector; Semantic Conventions — рычаг управления, делающий сигналы коррелируемыми; head sampling дёшев-но-слеп, tail sampling курируем-но-stateful, скомбинированы в паттерне ParentBased + tail; топология agent-to-gateway с маршрутизацией по хешу trace_id делает tail sampling возможным; а Collector — инфраструктура критического пути, требующая HA, персистентной очереди и самомониторинга, чтобы его собственный отказ был наблюдаем.
</Recap>
