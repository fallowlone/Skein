<Hook>
Каждая команда выполняется *где-то* — в конкретном каталоге. Если ты не знаешь, где находишься, нельзя надёжно именовать файлы или понять, почему команда не работает. Файловая система имеет форму — дерево — и две команды позволяют прочитать твою позицию в этом дереве и перемещаться по нему. Эти две команды лежат в основе почти всего, что ты будешь делать в терминале.

К концу урока ты будешь знать, как устроено дерево файловой системы Linux, как вывести текущее местоположение командой `pwd` и как перемещаться командой `cd` с помощью абсолютных и относительных путей.
</Hook>

<Step n={1}>
**Файловая система — единое дерево с корнем `/`.** На Linux (и Unix-подобных системах) каждый файл и каталог живёт где-то внутри одного дерева. Корень этого дерева называется `/` (один прямой слеш). Под `/` находятся известные каталоги верхнего уровня: `/etc` (файлы конфигурации), `/home` (домашние каталоги пользователей), `/var` (переменные данные: логи), `/usr` (программы), `/tmp` (временные файлы). Каждый путь в системе начинается с `/`.

Буквенных обозначений дисков, как `C:\`, нет. Всё — включая внешние диски, подключённые после загрузки — присоединено где-то внутри одного и того же дерева.
</Step>

<Step n={2}>
**`pwd` выводит твой рабочий каталог.** У оболочки всегда есть *текущий рабочий каталог* — каталог, в котором она «стоит» прямо сейчас. Команды, принимающие имя файла, используют этот каталог по умолчанию, если путь не указан явно. `pwd` (print working directory — вывести рабочий каталог) говорит, где ты находишься:

```bash
pwd
```

Типичный вывод:

```
/home/alice
```

Этот `/home/alice` — **абсолютный путь**: он начинается от корня `/` и перечисляет все каталоги до пункта назначения.
</Step>

<Step n={3}>
**`cd` перемещает твой рабочий каталог.** Передай абсолютный путь — и ты прыгаешь в точное место, независимо от того, где сейчас находишься:

```bash
cd /etc
pwd
```

Вывод:

```
/etc
```

Передай относительный путь — и оболочка интерпретирует его, начиная с *текущего* каталога:

```bash
cd /home/alice
cd projects
pwd
```

Вывод:

```
/home/alice/projects
```

`projects` был разрешён относительно `/home/alice` (где ты был), поэтому ты оказался в `/home/alice/projects`.
</Step>

<Step n={4}>
**Три сокращения навигации экономят постоянный набор.** Оболочка определяет три специальных имени каталога:

- `.` — сам текущий каталог. `cd .` ничего полезного не делает; но `ls .` выводит список здесь.
- `..` — родительский каталог. `cd ..` перемещает на один уровень вверх, к корню.
- `~` — твой домашний каталог (например, `/home/alice`). `cd ~` всегда возвращает домой. Голое `cd` без аргумента делает то же самое.

Их можно комбинировать: `cd ../../etc` означает «подняться на два уровня, затем войти в `etc`».
</Step>

<WorkedExample lang="ru">
**Сеанс навигации.**

Начиная с `/home/alice`, перейди в `/etc`, осмотрись, затем вернись домой:

```bash
pwd
```
```
/home/alice
```

```bash
cd /etc
pwd
```
```
/etc
```

```bash
ls
```
*(выводит файлы конфигурации в /etc)*

```bash
cd ..
pwd
```
```
/
```

```bash
cd ~
pwd
```
```
/home/alice
```

Обрати внимание: `cd ..` из `/etc` перешёл в `/` (родитель `/etc`), а не в `/home/alice`. Рабочий каталог сдвинулся на один шаг к корню дерева.
</WorkedExample>

<Inset kind="why" lang="ru">
На macOS дерево файловой системы устроено так же, и `pwd`/`cd` ведут себя идентично. Структура верхнего уровня отличается от Linux: `/Users` вместо `/home`, `/System` и `/Library` вместо `/usr/lib` и т.д. Концепции — корень, абсолютные пути, относительные пути, `.`/`..`/`~` — идентичны.
</Inset>

<Inset kind="mistake" lang="ru">
Распространённая ошибка — путать `/` (корневой каталог) с `~` (домашний каталог). `cd /` переносит тебя на самую верхушку дерева — оттуда видны `etc`, `home`, `var` и остальное. `cd ~` переносит тебя в *твой личный каталог* внутри `/home`. Это совершенно разные места. Всегда запускай `pwd`, если не уверен, где находишься.
</Inset>

<Recap lang="ru">
Файловая система Linux — это **дерево** с корнем `/`. Каждый файл имеет местоположение, выраженное как путь через это дерево. **`pwd`** выводит твой текущий рабочий каталог — твою позицию в дереве. **`cd`** перемещает тебя: дай ему **абсолютный путь** (начинается с `/`), чтобы прыгнуть в точное место, или **относительный путь** (начинается с текущего места) для пошаговой навигации. Сокращения **`.`** (здесь), **`..`** (родитель) и **`~`** (домой) ускоряют навигацию. Запускай `pwd` всякий раз, когда чувствуешь, что потерялся — оболочка всегда знает, где она находится, и теперь ты тоже.
</Recap>
