A 30 MB object blocks the sender ~30 ms, erasing the benefit of moving work off-thread. Transfer passes the object in postMessage's second argument (a transfer list); the browser hands the underlying memory to the receiver in O(1) and detaches the sender's view (byteLength becomes 0). Transferables include ArrayBuffer, MessagePort, ImageBitmap, OffscreenCanvas, and the stream types. Use transfer for large binary payloads where the sender is done with the data; use SharedArrayBuffer when both threads need concurrent access to the same memory (e.g. a WASM thread pool sharing a frame buffer) — transfer moves exclusive ownership, SAB shares it." },

A newly installed worker then enters waiting: it does not take control of already-open pages until every tab on the old worker closes. This prevents version skew — a page that loaded version N's HTML finishing its session against N+1's cached assets. activate fires after waiting (clean up stale caches, optionally clients.claim()), then the worker handles fetch events, intercepting requests in scope. skipWaiting() + clients.claim() overrides waiting to activate immediately — safe only with content-hashed assets." },

When both are in effect, self.crossOriginIsolated is true and SharedArrayBuffer is defined; otherwise it is undefined and multithreaded WASM silently degrades to single-threaded. The gate exists because Spectre made high-resolution shared-memory timers a side-channel risk. The cost: COEP blocks every cross-origin image, font, script, and iframe that does not send Cross-Origin-Resource-Policy — so audit each asset (serve CORP, proxy it, or use credentialless for public assets) and roll out in report-only mode first to enumerate breakage before enforcing." },

The two safety controls are backpressure and priority routing. Backpressure caps the job queue: when full, either drop the oldest jobs or reject new ones (return a rejected promise) so callers back off, instead of letting the queue grow unboundedly and the tab balloon. Priority routing puts interactive jobs (a filter preview the user is waiting on) ahead of background work (thumbnail generation). The illusion breaks for chatty interfaces: many small methods called in a tight loop pay a task hop per call and serialise the program on the round-trips. Design worker APIs coarse — one call that does a batch of work and returns a batch of results — exactly like minimising network round-trips.
