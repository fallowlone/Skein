<Recap lang="en">
The unit's through-line is one sentence applied five ways: a 304 saves the body bytes, never the round-trip. Revalidation is a versioning handshake — fingerprint, echo, compare — and it only works when the ETag is a pure function of the content, so every node agrees. Strong validators promise byte identity (mandatory for range requests); weak ones promise semantic equivalence, and If-None-Match compares weakly anyway, so the distinction mostly bites on resumed downloads. ETags beat Last-Modified on precision because timestamps have a one-second blind spot. And the failures — per-node tokens, mtime drift, compression changing the bytes — all resolve back to the same rule: keep the ETag content-derived. Now when you review a caching incident, run that check first: is the ETag derived from the content or from the node? The answer tells you whether a 304 is even possible.
</Recap>
