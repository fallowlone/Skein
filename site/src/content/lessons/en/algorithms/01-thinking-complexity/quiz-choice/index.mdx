  choices={[
    { label: "O(n log n) — the loop runs n times and each iteration does O(log n) work, so the costs multiply: n × log n.", correct: true },
    { label: "O(n + log n) — one loop plus one search, so add the two.", misconception: "You add complexities only for sequential, independent phases. Here the search is INSIDE the loop, so it runs once per iteration — the costs multiply, giving O(n log n)." },
    { label: "O(n) — binary search is so fast it counts as a constant.", misconception: "log n is not constant; it grows with n (slowly). It cannot be dropped to O(1). Per-iteration O(log n) work across n iterations is O(n log n)." },
    { label: "O(n²) — a loop with anything inside it is quadratic.", misconception: "Quadratic comes from a loop whose inner work is O(n), i.e. another full n-pass. Here the inner work is O(log n), not O(n), so it is O(n log n), well below O(n²)." },
  ]}

<Recap lang="en">
The through-line of the unit is one habit: before you run anything, estimate the cost. Count steps, keep only the dominant term, name the Big-O class, weigh time against space for your real constraint, and let the input bound tell you which class is even allowed. And never confuse cost with correctness — Big-O measures how fast, a loop invariant proves whether it is right at all.
</Recap>
