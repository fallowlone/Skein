<Idea>
Pseudocode is a way to write down an algorithm using a mix of natural language and lightweight programming‑like constructs. It’s not meant to run on a computer; it’s meant to be read by humans.  
The goal is to capture the **logic** — what steps happen, in what order, and under what conditions — without getting bogged down in the syntax of any particular language (Python, Java, C++, etc.).  
Because pseudocode is informal, different books and courses use slightly different styles, but they all share the same core ideas:
- **Variables** hold data (like `num`, `list`, `found`)
- **Assignment** gives a variable a value (often shown as `←` or `=`)
- **Input/Output** get data from outside or show results (`read`, `write`, `print`)
- **Conditionals** choose between paths (`if`, `else`)
- **Loops** repeat steps (`for`, `while`)
</Idea>

<Code>
Here’s pseudocode for finding the largest number in a list:

```
algorithm findMax(list):
    if list.length == 0:
        return null
    max ← list[0]
    for i from 1 to list.length - 1:
        if list[i] > max:
            max ← list[i]
    return max
```

Let’s break it down:
- `algorithm findMax(list):` — names the procedure and its input
- `if list.length == 0:` — handles the empty‑list edge case
- `max ← list[0]` — starts with the first element as the current max
- `for i from 1 to list.length - 1:` — looks at every other element
- `if list[i] > max:` — compares each element to the current max
- `max ← list[i]` — updates max when we find a bigger value
- `return max` — gives back the biggest value we saw
</Code>
