Use binary search when you are locating a single value, a boundary, or bisecting a monotonic predicate (binary search on the answer): O(log n) per query. Use two pointers (or a sliding window) when you sweep the structure for a relationship between elements — pair-sum, closest pair, longest valid window — in O(n) time and usually O(1) space. The deciding factor is space and access pattern: two pointers needs no extra memory and one linear pass; binary search shines for repeated point lookups. Topological sort orders a directed acyclic graph by dependency and simultaneously detects cycles (if it cannot order all nodes, a cycle exists) — the tool for build orders and scheduling. Union-Find (disjoint set) answers connectivity and cycle detection in UNDIRECTED graphs and drives Kruskal's MST.
