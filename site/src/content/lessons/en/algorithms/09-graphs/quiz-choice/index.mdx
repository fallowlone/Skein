  choices={[

  question="A pricing graph has some edges that represent refunds (negative cost). An engineer runs Dijkstra and gets answers that are sometimes too high. Why, and what is the fix?"
  choices={[
    { label: "Dijkstra's settle step locks a vertex's distance as final when it is popped, assuming no later route can be cheaper.     { label: "The min-heap cannot store negative numbers, so distances overflow.", misconception: "Heaps store negative numbers fine. The real defect is the settle invariant: settling commits a distance that a later negative edge could undercut. The bug is algorithmic, not numeric." },
    { label: "Dijkstra needs the graph to be undirected; directed refund edges confuse it.", misconception: "Dijkstra handles directed graphs correctly. The problem is specifically negative weights, not edge direction. Bellman-Ford, not undirecting the graph, is the fix." },

  question="Edges arrive one at a time over a stream, and after each edge you must answer 'are u and v in the same component yet?' instantly. Which structure fits, and why is re-running BFS the wrong choice?"
  choices={[
    { label: "Union-Find (DSU). It merges sets incrementally with union(u, v) and answers connectivity as find(u) === find(v) in amortized near-constant time. Re-running BFS after every edge is O(V + E) per edge — wasteful for an online stream.", correct: true },
    { label: "An adjacency matrix, because the cell [u][v] answers connectivity in O(1).", misconception: "A matrix cell only says whether a DIRECT edge u-v exists, not whether u and v are connected through a path.     { label: "BFS from u after each edge, since it is simple and correct.", misconception: "It is correct but the cost is O(V + E) per query, repeated for every arriving edge. DSU answers the same query in amortized O(alpha(n)) with no re-traversal — the whole reason DSU exists." },
    { label: "Topological sort, recomputed after each edge.", misconception: "Topological sort orders a DAG; it does not answer undirected connectivity, and it is undefined once the stream introduces a cycle. DSU is the dynamic-connectivity structure." },
  ]}

<Recap lang="en">
The unit's through-line is one modeling decision tree: pick the representation by density (list for sparse, matrix for dense or O(1) edge lookup); pick the traversal by what you need (BFS for fewest-edge paths and levels, DFS for depth and cycle structure); add weights and BFS yields to Dijkstra — but only with non-negative edges, else Bellman-Ford. Topological sort orders a DAG and detects cycles for free, and union-find answers dynamic connectivity in amortized O(alpha(n)) where re-running BFS would be wasteful. Match the algorithm to the problem's shape before writing a line of code.
</Recap>
