## Snippet 1 — read the binary number

```
bit:    1  0  1  1  0  1  0  0
weight: 128 64 32 16 8  4  2  1
```

## Snippet 2 — decode the ASCII bytes

```
byte 1: 01001000   (decimal 72)
byte 2: 01101001   (decimal 105)
ASCII reference: 'A'=65  'H'=72  'a'=97  'i'=105
```

## Snippet 3 — evaluate the boolean expression

```
expr = NOT A OR (B AND C)
inputs: A = 1, B = 1, C = 0
precedence: NOT first, then AND, then OR
```

<Quiz
  id="01-what-a-computer-is-code-3"
  lessonSlug="01-what-a-computer-is"
  lang="en"
  question="Evaluating by the stated precedence, what is the result?"
  choices={[
    { label: "0 — NOT A = NOT 1 = 0; B AND C = 1 AND 0 = 0; then 0 OR 0 = 0.", correct: true },
    { label: "1 — evaluate left to right: NOT A OR B is 0 OR 1 = 1, then AND C.", misconception: "Precedence is NOT, then AND, then OR — not strict left to right. The parenthesised AND binds B and C first: NOT A (=0) OR (B AND C = 0) = 0." },
    { label: "1 — NOT applies to the whole expression A OR (B AND C).", misconception: "NOT binds tightest and applies only to A, giving NOT A = 0. It does not negate the entire expression. Result is 0." },
    { label: "Undefined — you cannot mix AND and OR in one expression.", misconception: "Mixing is fine; precedence resolves it. NOT, then AND, then OR yields a single value: here 0." },
  ]}
/>

## Snippet 4 — trace the half-adder

```
half-adder:
  sum   = A XOR B   (1 only when inputs differ)
  carry = A AND B   (1 only when both are 1)
inputs: A = 1, B = 1
```

<Quiz

  question="What sum and carry does the half-adder produce for A=1, B=1, and why does that match adding the bits?"
  choices={[

    { label: "sum = 1, carry = 1, because 1 + 1 = 2 and both outputs go high.", misconception: "The sum bit is the XOR, which is 0 when inputs are equal. 1 + 1 is binary 10: sum bit 0, carry bit 1 — not sum 1." },
    { label: "sum = 1, carry = 0, since XOR of 1 and 1 is 1.", misconception: "XOR is 1 only when inputs DIFFER. For two 1s, XOR is 0. So sum = 0 and the carry (AND) is 1." },
    { label: "sum = 0, carry = 0 — both gates output 0 when inputs match.", misconception: "AND of two 1s is 1, so the carry is 1, not 0. Only the XOR sum is 0 here." },
  ]}

<Recap lang="en">
Every snippet was the unit's reading loop in miniature: a binary number is the place-value sum of its 1-bits; an ASCII byte is a number until an encoding names it a letter; a boolean expression resolves by NOT-then-AND-then-OR; and a half-adder's XOR-sum and AND-carry reproduce single-bit addition exactly. Bits plus a rule give meaning — that is the entire unit in four reads.
</Recap>
