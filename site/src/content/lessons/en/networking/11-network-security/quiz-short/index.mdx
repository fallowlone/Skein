SYN cookies avoid storing any state: when the backlog would overflow, the server encodes the connection parameters into the ISN as a hash of source/dest/port/timestamp and sends the SYN-ACK without allocating a slot. A legitimate client returns a correct ACK from which the server reconstructs state; spoofed floods produce no valid ACK and consume no memory. The tradeoff is memory-for-CPU: a hash computation per accepted connection instead of a stored backlog entry." },

RPKI/ROV protects BGP routing: resource holders publish ROAs declaring which AS may originate which prefix, and routers enforcing ROV reject announcements from unauthorized ASes (route hijacks/leaks).
