The split: the routing table is the control-plane structure built by BGP/OSPF/IS-IS, holding all known prefixes, attributes, and alternatives; the FIB is the trimmed per-destination next-hop view compiled into TCAM hardware for line-rate, nanosecond lookups on the data plane. When it reaches zero the router discards the packet and sends an ICMP 'time exceeded' back to the source; this stops misrouted packets from looping forever. traceroute weaponises this: it sends probes with TTL = 1, 2, 3, …; each router whose decrement hits zero replies with 'time exceeded', and that reply reveals the router's address and RTT. Incrementing TTL one at a time traces the path hop by hop. A hop that withholds or rate-limits ICMP shows as asterisks while still forwarding data." },

A black hole happens when a firewall or middlebox silently drops that ICMP — the sender never learns, keeps sending full-size packets, and they keep being dropped. Small requests fit under the path MTU and succeed; large payloads exceed it and hang, often with ~1s retransmit cycles. The robust fix is TCP MSS clamping — a gateway rewrites the MSS option in SYNs to a safe value so endpoints never build an oversized packet — or PLPMTUD (RFC 4821), which probes with TCP segments; both work without depending on ICMP surviving the path. (Unblocking ICMP only helps where you control every middlebox.)" },

CGNAT stacks a second NAT layer, making this worse and rendering per-IP rate-limiting meaningless. NAT is not security: it does not inspect traffic, enforce policy, or stop a compromised internal host from reaching out.
