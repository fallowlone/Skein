The cost is privacy: the user's network prefix becomes visible to every server in the delegation chain. Privacy-focused resolvers (Cloudflare 1.1.1.1, Apple iCloud Private Relay) disable ECS and accept slightly worse routing." },
    { q: "How is a CDN cache key built, and why is a Vary: User-Agent header a footgun?", a: "The default key is URL + HTTP method + Host; the response's Vary header extends it with the listed request-header dimensions, so the cache keeps a separate entry per distinct value of each Vary header. Vary: Accept-Encoding (~5 values) and Accept-Language (~10–50) are safe. Vary: User-Agent has thousands of distinct values (every browser × version × OS), so the cache fills with single-use entries that are never reused and hit rate collapses to near zero. To serve mobile vs desktop, detect device at the edge and rewrite the URL, or serve responsive HTML — never key on the raw User-Agent." },
    { q: "What does an origin shield do, and how many origin requests does it generate when 200 edges in a region all miss the same cold URL at once?", a: "An origin shield is a regional intermediate cache between the edge POPs and origin: all edges in a region funnel their misses through one shield node, which holds a larger, longer-lived cache. When 200 edges miss the same URL simultaneously, they all forward to the shield; the shield makes one outstanding origin request, the other 199 wait, and the single origin response is fanned out to all 199 plus cached. Origin sees one request instead of 200 — the shield is the first line of defence against the thundering herd." },
    { q: "Explain the cache stampede and how stale-while-revalidate inverts it.", a: "A stampede happens when a popular cached entry expires and many concurrent requests all miss simultaneously, each firing its own origin fetch; origin is overwhelmed, may return 5xx, and the CDN may cache those errors. The amplification is roughly (concurrent requests at expiry) × (origin response time). stale-while-revalidate=N inverts it: after max-age expires, the edge serves the stale copy instantly to every request and sends exactly one background revalidation to origin. All users get a fast response; origin sees one request instead of thousands. The trade-off is that content can be up to N seconds stale, so set N to the staleness the content type tolerates." },

This beats a single whole-page TTL because no one TTL is right for all parts — a short TTL hammers origin and a long one shows stale prices. Cache-tag purge handles invalidation at scale: origin stamps responses with semantic tags (Cache-Tag: article-1001, category-tech), and an edit purges by tag in 1–5 s across all POPs, turning O(URLs) purge calls into O(tags), usually one to five." },
