<Recap lang="en">
This is the loop you will run on every real secrets incident and migration: treat a committed secret as leaked and rotate first, scrub history only as hygiene, move the value into a manager with access control and an audit trail, gate the repo with a scanner so the next mistake never lands, enforce least privilege, and climb to dynamic short-lived credentials whose TTL bounds the blast radius. Doing it once on a small service, with evidence at each rung, makes the production version muscle memory. Now when you see a live key in a diff or an alert fires at 3am, you will know exactly which step comes first — and which step is only hygiene.
</Recap>
