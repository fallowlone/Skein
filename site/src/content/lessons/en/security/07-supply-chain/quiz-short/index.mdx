The defense is precedence, not luck: own a scoped namespace like @acme/ on the public registry so no one else can publish under it; configure the package manager so the private registry has strict precedence for your scope, or block the public registry for internal scopes; mirror public packages through one proxy; and as belt-and-braces, publish placeholder packages under your internal names yourself so the name is simply taken." },
