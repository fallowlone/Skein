    { label: "Not a vulnerability — the id was a valid integer and the query was safe.", misconception: "A syntactically valid request that returns another user's data is the textbook IDOR shape of Broken Access Control, the #1 category in 2021." },

<Quiz
  id="01-owasp-modern-choice-5"
  lessonSlug="01-owasp-modern"
  lang="en"
  question="A non-admin sends POST /api/admin/users/7/promote directly with curl and it succeeds — the only 'check' was that the admin button is hidden in their UI. Category and fix?"
  choices={[
    { label: "Broken Access Control — missing function-level authorization. Hiding UI is not a control; the endpoint must enforce the role/permission server-side, deny by default, on the actual action.", correct: true },
    { label: "Security Misconfiguration — the admin route was left exposed.", misconception: "The route is supposed to exist; the defect is that it does not verify the caller's role. That is a missing authorization check (A01), not a misconfigured setting." },
    { label: "Cryptographic Failures — sign the request so it can't be forged.", misconception: "A signature proves the message was not tampered with, not that this caller may promote a user. The missing piece is a server-side role check." },
    { label: "It's not a vulnerability because legitimate admins use the same endpoint.", misconception: "Shared endpoints are normal; the bug is that authorization is never enforced, so a non-admin reaching it directly succeeds." },
  ]}

<Recap lang="en">
The through-line is reading a finding back to its root cause: a parameterized query that still leaks rows is access control, not injection; a renamed category points at cause over symptom; a trusted client price is insecure design no filter can fix; SSRF earned its slot by practitioner vote, not data; hidden UI is never authorization; and a vulnerable dependency plus verbose errors are two categories where the patch outranks the hardening. Now when you spot a finding in a review, the first move is naming the root cause — then the right fix becomes obvious and the bolt-on impulse easy to resist. Now when you face an unfamiliar finding, ask: what class of thing went wrong, and what would have to change at the design level so this couldn't happen again?
</Recap>
