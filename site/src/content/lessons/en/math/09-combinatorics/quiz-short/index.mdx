You multiply rather than add because each option of the first choice opens a fresh full set of the second choice's options. With 3 shirts and 2 trousers, shirt 1 pairs with both trousers, and so does shirt 2, and shirt 3 — that is 2 + 2 + 2 = 3 × 2 = 6.     { q: "What is a factorial, and what does n! count?", a: "The factorial of a whole number n, written n!, is the product n × (n − 1) × ... × 2 × 1 — you multiply n down to 1. So 3! = 6, 4! = 24, 5! = 120. It counts the number of ways to arrange all n distinct items in order: the first position has n choices, the next n − 1, and so on as each placed item is used up. Factorials grow extremely fast, faster than exponentials, which is why even modest arrangement problems produce huge counts." },
    { q: "Define a permutation, and explain why the choices shrink by one at each position.", a: "A permutation is an arrangement in which order matters — seating people in a row, ordering books, awarding distinct 1st and 2nd prizes. You count it by the counting principle, but the option counts shrink: the first position can be any of n items, but once one is placed it is used up and cannot reappear, so the second position has only n − 1 left, the third n − 2, and so on. Arranging all n items is n!; arranging only r of them takes just the first r shrinking factors, e.g. 3 of 5 is 5 × 4 × 3 = 60." },
    { q: "Define a combination, and explain how it relates to a permutation.", a: "A combination is a selection in which order does not matter — the group {A, B} is the same as {B, A} because it holds the same members. It is always fewer than the matching permutation. To count it, first count the ordered picks (a permutation: the first r shrinking factors of n), then divide by r!, the number of orderings of the r chosen items. Choosing 3 of 5: ordered picks are 5 × 4 × 3 = 60, divided by 3! = 6 gives 10. The division merges every group's r! orderings back into the single group they always were." },
    { q: "You face a counting problem. If they are separate choices (a main, a side, a drink), use the counting principle — multiply the option counts. If you are drawing from one set, ask the second question: does order matter? If it does (seats in a row, ranked prizes), it is a permutation — multiply the shrinking factors. If it does not (an unordered team, a hand of cards, pizza toppings), it is a combination — count the ordered picks and divide by r!. Order-matters versus order-does-not is the hinge that separates the two." },

Mechanically, the combination count is the permutation count n! divided by n! (the orderings of the chosen group), which equals 1. It is the clearest illustration that dividing by r! is exactly cancelling the orderings you decided not to distinguish." },

<Recap lang="en">
If you could reconstruct each answer from memory, you hold the unit's spine: the counting principle multiplies independent choices because each early option opens a fresh set of later ones; a factorial counts the orderings of a whole set; a permutation multiplies shrinking factors because placed items are used up; and a combination divides the permutation count by `r!` to merge the orderings order does not care about. Every problem starts with two questions — separate choices or one set, and does order matter.
