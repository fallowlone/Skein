    { q: "What is a function, and what is the one rule it must obey?", a: "A function is a rule that turns an input into an output — you put a number (or thing) in, the rule acts on it, and a result comes out. The one rule it must obey is that each input has exactly one output: feed the same input in twice and you must get the same output both times. A vending button that sometimes drops one snack and sometimes another is not a function. The rule need not be a formula; a table or a picture is a function too, as long as every input maps to exactly one output." },
    { q: "What does the notation f(3) mean, and how do you find its value?", a: "Function notation names the rule with a letter and shows the input in brackets, so f(3) means feed the input 3 into the rule f. To find its value you substitute 3 wherever the input appears in the rule and compute. If f(n) = n + 5, then f(3) = 3 + 5 = 8. The thing inside the brackets is always the input; the number you get back is the output. The same input always returns the same output, which is exactly what makes f a function." },
    { q: "What are the domain and range of a function, and how do they differ?", a: "The domain is the set of inputs you are allowed to feed into the function — what may go in. The range is the set of outputs it can produce — what comes out. They are different sides of the machine: the domain is on the input side, the range on the output side. For a vending machine that takes buttons A1, A2, A3 and drops three snacks, the domain is the three buttons and the range is the three snacks. Naming them is just naming what is allowed in and what can come out." },
    { q: "What makes a function linear, and what are its two parts?", a: "A function is linear when its output changes by the same fixed amount for every 1-step change in the input — a constant step, never speeding up or slowing down. It has two parts: a rate (the slope), which is the number multiplied by the input and equals the per-step change; and a starting value, which is the output when the input is 0. The taxi rule 2n + 3 has slope 2 (two coins per kilometre) and starting value 3 (the fare before moving). Every linear function fits this rate-times-input-plus-starting-value shape." },
    { q: "Why does a linear function always graph as a straight line?", a: "On a graph the horizontal axis carries the input and the vertical axis the output, and each input-output pair becomes a point written (input, output) — across first, up second. A linear function moves up by the same fixed step for every 1 step across. Because the rise is the same at every input, the points can never bend: a curve would require the step to change, but a constant step can only trace a single straight line. Seeing a straight line is therefore how you recognise a linear function at a glance." },
    { q: "Given the graph of a function, how do you read the output for a chosen input?", a: "Start on the horizontal (input) axis at the value you want — say 4. Move straight up from that spot until you meet the function's line or curve. Then look across to the vertical (output) axis: the height where you landed is the output for that input. For y = 2x, going up from input 4 meets the line at height 8, so the output is 8. This is just reading a point the other way round — you supply the input position and the graph hands you the matching output." },
