8 NAV SPECIMENS

Альтернативные макеты навигации вместо сайдбара. Вариант B (верхняя плашка) уже стоит на главной прототипа — здесь остальные семь: от рабочих до вызывающих. Каждый — живой кусок вёрстки, сожми окно до 390px и покликай.

01COMMAND BAR — навигация как поисквердикт: смело, но требует привычки
SKEIN® Войти →

Суть: разделов нет вообще — только командная строка палитры. Плюс: ноль хрома, быстрые руки. Минус: discoverability нулевая для новичков; due-бейдж негде показать; нужен фолбэк-индекс для гостей и поисковиков.

02BOTTOM DOCK — плавающая пилюля снизувердикт: провокация, не для учебы
Atlas Plan Review Projects Me

Суть: мобильный паттерн на десктопе — док всегда под рукой. Плюс: боковой гаттер свободен, большие тапы. Минус: перекрывает контент и CTA-плиты; ломает привычку «навигация сверху/слева»; 8 разделов не влезут.

03SLIM RAIL 48px — та же рельса, но струнавердикт: компромисс без сноса
SKEIN — ATLAS
48PX ВМЕСТО 232PX · ПОДПИСИ В ТУЛТИПАХ

Суть: рельса остаётся, но всегда в icon-режиме: 48px, квадраты-маркеры, вертикальная подпись. Плюс: ноль новой механики — существующие брейкпоинты уже это умеют; гаттер почти свободен. Минус: подписи только в тултипах (на тачах их нет); due-бейдж превращается в точку.

04MARQUEE NAV — меню, которое убегаетвердикт: чистая провокация
AtlasRoadmapReviewInterviewProjectsEnglish AtlasRoadmapReviewInterviewProjectsEnglish

Суть: разделы едут контурной бегущей строкой; ховер заливает слово, активный — оранжевый. Плюс: максимальная кинетика, ноль хрома. Минус: цели движутся (мимо WCAG 2.2 по движущимся целям); клавиатурой — только табом вслепую; поиск и аккаунт некуда деть. Как арт — да, как навигация — нет.

05MASTHEAD — газетная шапкавердикт: годен для маркетинга

Суть: nameplate как в газете: дата/тираж сверху, гигантское имя, линейка разделов под ним. Плюс: editorial-характер сильнее всех вариантов; разделы читаются мгновенно. Минус: съедает ~250px вертикали; липкой её не сделаешь — значит, внутри длинных страниц навигация пропадает.

06CHROMELESS — шапки нет, есть оглавлениевердикт: годен для лендингов

Суть: глобального хрома нет вообще — страница открывается гигантским оглавлением разделов, дальше только футер. Плюс: максимум воздуха под плакат; навигация = контент. Минус: работает только на входных страницах; внутри продукта (трек, калибровка) без шапки теряешься; поиск/аккаунт живут только в футере.
