## Блокирующее

### B1. Инфографики шире колонки в 2–6 раз → подписи нечитаемы

**Где:** сгенерированные SVG в `site/src/content/lessons/**/infographics/*.svg`,
рендер через `src/components/diagram/Infographic.astro`.

**Факты.** Колонка урока — `max-width: 680px` (`src/layouts/Lesson.astro:293`).
`Infographic.astro:28` задаёт `.ig svg { max-width: 100%; height: auto }`, то есть
SVG **сжимается**, а не скроллится. Замер по всем 1583 сгенерированным файлам:

| порог | файлов | доля |
|---|---|---|
| > 700 px | 1237 | 78.1% |
| > 900 px | 866 | 54.7% |
| > 1200 px | 488 | 30.8% |
| > 2000 px | 81 | 5.1% |
| > 3000 px | 26 | 1.6% |

p50 = 971 px, p90 = 1618 px, max = 4300 px
(`ru/observability/02-structured-logging/06-trace-context-in-logs/infographics/context-by-runtime.svg`).

Шрифт внутри этих SVG — 14–18 px. При ширине 3580 px, сжатой до ~640 px
(коэффициент 0.18), надпись 14 px рендерится как ~2.5 px. Это не «мелко», это
нечитаемо совсем.

**Почему так вышло:** AntV раскладывает текст в одну строку и расширяет холст
вместо переноса. Последний коммит `39e538b15` («wrap-aware text layout») лечил
перекрытие текста, но ширину не ограничил.

**Что делать:** ограничить холст на этапе генерации (`scripts/gen-infographics.mjs`)
— целевая ширина ≤ 900 px с принудительным переносом; для широких схем сменить
стратегию отображения на горизонтальный скролл (`.dframe-body` уже имеет
`overflow-x: auto`, но `max-width: 100%` на SVG его обесценивает). Добавить в
линтер порог по ширине сгенерированного SVG, иначе регресс вернётся.

### M3. Определения глоссария исчезают для скринридера после гидратации

здесь это ссылка на определение — тег выбран неточно.

**Фикс:** оставить доступное описание (`aria-describedby` на скрытый элемент с
текстом, либо не удалять `title`), задать роль кнопки/ссылки, если элемент

скринридера теряется — она должна быть снаружи именованного региона.

### M10. Нет структурированных данных (JSON-LD)

Ни одного `application/ld+json` в проекте. `SeoHead.astro` покрывает title,
description, canonical, OG, Twitter, hreflang — но для учебного сайта отсутствуют
`Course` / `LearningResource` / `BreadcrumbList` / `Organization`. Это прямой
недобор в выдаче (rich results) при уже готовом контенте.

Мелочь рядом: `src/pages/admin.astro` исключён из sitemap и закрыт в
`robots.txt`, но `<meta name="robots" content="noindex">` на нём нет — в отличие
от `404.astro:11` и `_dev/editorial-diagrams.astro:98`.

### M11. Заголовок внутри ссылки-карточки

На главной и в `/learn/` — 44 случая `<a> … <h2> … </a>`
(`pages/[lang]/index.astro:99`). Формально валидно и распространено, но
скринридер читает всю карточку как один длинный текст ссылки, а список
заголовков документа при этом состоит из элементов, которые нельзя
активировать отдельно. Приемлемый компромисс — оставить `h2` вне ссылки, а
ссылку растянуть псевдоэлементом.

### M12. Дубль CSP: два независимых источника

`site/src/lib/csp.ts` (в `<meta http-equiv>`) и
`functions/lib/response.ts:20` (в HTTP-заголовке) описывают политику дважды.
Сейчас они совместимы: заголовок всегда содержит `wasm-unsafe-eval` и
`worker-src`, meta добавляет их только при `cspExtra="wasm"`, а браузер
применяет пересечение — на страницах уроков WASM разрешён, на остальных не нужен.

Активного дефекта нет, но правка одного файла без второго **тихо** сломает
песочницы (QuickJS, PGlite) или, наоборот, ослабит политику. Стоит вынести
политику в один общий модуль.

## Проверено и дефектом не является

Чтобы не тратить время на перепроверку:

- **`aria-hidden="true"` на модальном поиске с фокусируемыми элементами внутри**
  (`GlobalSearch.astro:37`) — аудитор помечает это на каждой странице, но
  `.gs-overlay` скрыт через `visibility: hidden` (`:72`), что выводит содержимое
  из порядка табуляции. Ложное срабатывание.
- **`Could not parse CSS stylesheet`** в выводе jsdom — это ограничение самого
  jsdom (`@container`, `color-mix()`, `oklch()`, `:has()`), а не невалидный CSS.
- **Дубли `id`** — не найдено ни одного ни на одной странице.
- **`target="_blank"` без `rel="noopener"`** — не найдено; `SourcesFooter` ставит
  `rel="noreferrer noopener"` корректно.
- **Положительный `tabindex`** — не найдено.
- **`<li>` вне списка, блочные элементы внутри `<p>`, вложенные интерактивные
  элементы** — не найдено.
- **`<img>` без `alt`** — не найдено (растровых изображений в контенте почти нет).
- **`prefers-reduced-motion`** — учтён в 24 файлах, включая все kit-стили;
  есть и рантайм-флаг `scripts/motion-flag.ts`.
- **Security-заголовки** (HSTS, nosniff, Referrer-Policy, Permissions-Policy,
  COOP/CORP) — ставятся в `functions/_middleware.ts` для всех ответов.
- **Ловушка фокуса в мобильном «рельсе»** (`TopNav.astro`) — реализована
  корректно: `role=dialog`/`aria-modal` на открытии, Esc, скрим, возврат фокуса.
- **`html lang`** — выставлен на всех страницах; `ThemeBoot` ставит `data-theme`
  до первой отрисовки, вспышки темы нет.
- **Паритет EN/RU контента** — расхождений нет ни в одном из 44 треков.
