## Порядок и границы работ

1. Завершить аудит цепочек действие → обратная связь → состояние → рекомендация,
   научных оснований и публичного состава.
2. Зафиксировать регрессии ложного mastery, потери состояния и расписания.
   Исправить общие механизмы, используя существующие хранилища и компоненты.
3. Связать один содержательно проверенный цикл с диагностикой, самостоятельной
   попыткой, коррекцией, отложенным воспроизведением и новой ситуацией.
4. Распространить механизмы на применимые типы заданий и направления; отдельно
   показать фактическое покрытие контента. Пилот не закрывает всю задачу.
5. Очистить только подтверждённые кандидаты по manifest отдельным коммитом.
   Лицензии, атрибуция, задания, тесты и нужные generated indexes сохраняются.
6. Независимые педагогическая, техническая и security-проверки; браузерные проверки
   EN/RU, мобильного и клавиатурного сценариев; публикация ветки и проверка CI.

## Проверка приёмки

- Слабый prerequisite → конкретная коррекция; диагностированное освоение → пропуск.
- Чтение, подсказка, самооценка и LLM сами по себе не доказывают mastery.
- Отложенная неудача меняет рекомендацию; recall и transfer различаются.
- Время, пропуски и повторные события не искажают расписание.
- Reload, язык, старые данные и экспорт/импорт сохраняют корректное состояние.
- AI поддерживает повторную самостоятельную попытку и отложенную проверку.
- BYOK бесплатен; платные API проверяют `entitlements.coach` на сервере.
- Ответы, код и записи об ошибках не уходят в аналитику по умолчанию.
- Сборка, content lint, EN/RU и доступность сохранены; проверки не ослаблены.
- Рост retention не заявляется по unit-тестам: необходим отдельный baseline
  и добровольная отложенная оценка на реальных учащихся.

## Выполнение

Начальный запуск `executor` отклонён runtime из-за закреплённой несовместимой
пары модели/effort. Пользователь разрешил любой executor. Репозиторный аудит
делегирован реальной роли `explore` (Luna); исправления — роли `debugger`,
проверка источников — роли `researcher`. Ведущий интегрирует результаты.

Найденный старый план от 2026-09-07 не используется как доказательство: наличие
списка шагов в `MasteryLoop` не подтверждает работающий учебный цикл.
