## Доказательства и пределы

- Две БД по 184 320 байт имеют одинаковый SHA-256:
  `e05d46251ada80f25cdf7bc043b103b1177a0ea0ecb8ea1fc8ebe88e9fe3f07f`.
  Проверены только схема и количество строк в read-only SQLite соединении;
  значения пользовательских данных не печатались. Подтверждения реального
  секрета или персональных ответов в этих пустых таблицах нет.
- Поиск `sessions.db|scheduled_tasks.lock` по исходникам и скрытым файлам,
  исключая `.git`, dependencies и dist, нашёл только существующее правило
  `**/sessions.db` в `.gitignore`. Игнорирование не снимает уже tracked файл.
- Ограниченный pattern scan tracked файлов до 2 MB не нашёл private-key
  заголовков, GitHub token pattern и AWS access-key pattern. Это не полный
  secret scan и не доказательство отсутствия секретов во всей истории.
- Cleanup не меняет visibility, лицензии, историю Git и удалённые secret stores.
  История не переписывается; отзыв секрета не заявляется.
