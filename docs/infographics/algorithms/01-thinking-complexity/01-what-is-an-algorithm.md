# 01 What is an algorithm

ROLE: Professional technical illustrator and educational UX designer.

AUDIENCE: Beginner developer.

GOAL: Explain that an algorithm is a deterministic sequence of steps that transforms input into output.

TYPE: Hero infographic.

MAIN FOCUS:

Large central pipeline:

`Input → Algorithm → Output`

SECONDARY CONCEPTS:

- ordered steps;
- rules;
- repeatable result.

SUPPORTING DETAILS:

Small examples: ingredients → recipe → meal, data → sorting algorithm → ordered data.

STYLE:

Minimal vector technical illustration. Documentation aesthetic. Clear icons.

QUALITY CHECK:

Keep the algorithm definition as the only idea. Avoid code-heavy examples.
