Open Atlas · Design Language · v0.1

One world,
from home to lesson.

A single editorial-cartographic system to replace the two disconnected visual languages. Paper & ink foundation, a quiet map metaphor, light + dark, bilingual EN/RU. The cosmic shell is removed — not blended.

01 / Assumption
Editorial paper is the base

Per §2.5 I'm unifying everything onto the paper/ink token system and dropping the cosmic palette. At most one restrained accent — a quiet ink-blue for actions and links.

02 / Direction
Map as structure, not décor

The atlas metaphor lives in a cartographic grid + route nodes (no starfield, no mountain). Progression is information architecture; the game layer is a calm rating, never arcade.

03 / For review
Tweak the dials, then we lock

Open Tweaks (toolbar) to push accent hue, paper warmth, type scale, contour density, radius and density. These are the dials we'll settle the token system on. Toggle EN/RU + theme to stress-test.
