# Monitoring Setup

## Production signals

Monitor these areas after launch:

- Authentication failures and abnormal session behavior.
- Payment creation, webhook processing, entitlement updates, and failed payments.
- Application errors and unexpected API failures.
- Build and deployment failures.
- Performance metrics: page load, client errors, slow routes, and large bundles.

## Critical alerts

Create alerts for:

- Payment webhook failures.
- Payment states stuck without entitlement updates.
- Authentication outage.
- High error rate.
- Failed deployments.

## First launch metrics

Review:

- active users;
- registrations;
- premium conversion;
- payment completion rate;
- most used features;
- client error rate.
